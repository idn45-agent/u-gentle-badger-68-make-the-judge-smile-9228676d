## What it does

`main.py` writes one line — at most 200 characters, about a small good thing
that happened today — to `/output/entry.txt`. Deterministic, standard library
only, no network.

The line:

> My neighbour's kid taped a drawing to my door this morning: me in a cape, holding a durian like a trophy.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
